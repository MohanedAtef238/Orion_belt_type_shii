# Orion Belt Thingy

Orion Belt thingy is a simple Node.js project that connects to real space APIs.

It pulls data from:
- NASA's Astronomy Picture of the Day
- The live location of the International Space Station  or ISS
- Upcoming rocket launches from Launch Library
---

The goal was to practice:
- Calling external APIs
- Updating data periodically (polling) 🐀🐀

Nothing fancy — just functional-ish @,@ .

---
the files were separated into services, tests and the main server.js
